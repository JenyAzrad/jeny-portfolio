# Jeny Azrad – Data Analyst Portfolio

Personal portfolio website showcasing my data analytics projects, skills and background.

**Live site:** https://jenyazrad.github.io/jeny-portfolio/

## About

Data Analyst with 20+ years of experience in technology and UX/UI. The site presents three featured projects:

- **Amazon E-Commerce – SQL** – data cleaning, relational modeling, CTEs, window functions and business KPIs
- **Employee Attrition – Python / Pandas** – exploratory data analysis of the factors behind employee turnover
- **Amazon E-Commerce – Power BI** – interactive dashboard with DAX measures and KPI analysis

All project files are in [Data-Analyst-Projects](https://github.com/JenyAzrad/Data-Analyst-Projects).

## Tech stack

React 18 · Vite · CSS · GitHub Actions + GitHub Pages

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

## Project structure

```
src/
  components/   Navbar, Hero, About, Skills, Projects, Background, Contact...
  data.js       projects, skills, links and timeline content
  styles.css    all styling
public/         resume PDF
```
